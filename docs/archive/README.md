# Archived planning

This folder contains superseded product, content and UX planning retained for historical context.

**Nothing here is current implementation authority.**

The documents are preserved because they explain how the product evolved and may contain useful design reasoning, but future work should start from the named issue/PR, executable code/tests and current `docs/product/` / `docs/rules/` authority instead.

Historical links inside archived files may refer to their original repository locations. Treat those paths as archaeology, not as evidence that the old structure is still current.
