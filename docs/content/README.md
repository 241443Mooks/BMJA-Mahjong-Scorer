# Content records

These files preserve source copy, page briefs and marketing/editorial material created while the public site evolved.

They are useful for provenance and wording archaeology, but **the live application and current product authority docs win if they differ**.

Typical uses:

- recover wording or rationale from an earlier public page;
- understand the intent behind a shipped content surface;
- reuse reviewed copy without treating an old page brief as a current product specification.

Do not use this folder as the source of truth for scoring rules, current routes, current product status or the active roadmap.
