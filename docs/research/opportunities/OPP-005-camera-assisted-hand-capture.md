# OPP-005 — Camera-assisted hand capture

**Status:** explore

## Jobs addressed

JTBD-007, JTBD-002.

## Opportunity

Use camera recognition to reduce manual tile entry only if it reduces **total hand-to-confirmed-score time**, including correction and context entry.

## Evidence reading

Camera has real use and some payment signal; it is also technically difficult and already competitively served. Recognition alone is not differentiation.

## Plus hypothesis

Manual/touch remains available. Camera may be paid convenience only if it materially beats touch on real physical hands.

## Key risks

Tile-design/lighting variance, correction overhead, meld/context information not visible in the image, existing competitors.

## Cheapest test

Benchmark identical hands using touch versus camera, including all correction and confirmation time.
