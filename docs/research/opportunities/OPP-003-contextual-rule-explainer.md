# OPP-003 — Contextual rule explainer

**Status:** promising

## Jobs addressed

JTBD-003, JTBD-001, JTBD-005.

## Opportunity

Answer “why does this apply here?” using the actual hand/table context and active rules profile, with concise source-linked reasoning.

## Differentiation hypothesis

The valuable object is not a generic rules encyclopaedia. It is an auditable explanation such as: “this result is X because A/B/C under table profile Y; this differs from the baseline here.”

## Commercial signal

Strongest relative direct satisfaction signal in the first research pass, but still too limited to validate subscription pricing.

## Key risk

A wrong contextual explanation is worse than no answer. Grounding, provenance and deterministic rule truth are non-negotiable.

## Cheapest test

Capture real in-session questions and compare concise contextual answers with current lookup/asking-the-expert behaviour.
