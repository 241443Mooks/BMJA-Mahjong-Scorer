**Status:** promising

Maintain one authoritative shared table state and settlement view so everyone can see scores, seats/winds and what happens next without duplicated bookkeeping.

Central phone mode, tablet/shared screen, glanceable score/round/wind tracker and rules-aware settlement.

Core single-table shared state likely belongs in Free. Cross-device/shared-display convenience is only a Plus candidate if live-table testing shows material value.

## Cheapest test

Compare central phone, tablet, cast/shared screen and paper during real sessions. Measure state questions/errors and hand-transition time.
