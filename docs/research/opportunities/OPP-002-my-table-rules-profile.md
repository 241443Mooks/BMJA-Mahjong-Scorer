# OPP-002 — My Table rules profile

**Status:** explore

## Jobs addressed

JTBD-001, JTBD-004, JTBD-003.

## Opportunity

Help a group describe how it plays, identify the closest recognised baseline, preserve confirmed differences, and reuse those rules in scoring, settlement and contextual explanations.

## Core model

**Understand -> Preserve -> Reuse.**

## Evidence reading

The problem is strongly supported: inherited/family rules, house rules and custom documents are real. What is **not** established is that users repeatedly reopen a digital profile or will pay for persistence.

## Cheapest test

Create profiles manually for 10–15 real groups, give them a useful shareable output, then follow 4–8 sessions and measure reopen/update/share/print/configure behaviour.

## Plus hypothesis

Only consider persistence/custom execution a paid retention feature if repeat use is observed. Do not build account infrastructure to prove the premise.
