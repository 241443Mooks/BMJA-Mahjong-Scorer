# Hypothesis verdicts

| Starting hypothesis | Verdict | Why |
|---|---|---|
| Low-friction scoring | **Strongly supported** | Repeated scoring pauses and visible calculators/tables/spreadsheets; must beat expert/manual alternatives end-to-end. |
| Ruleset identification | **Supported** | Family/inherited players can describe how they play without knowing the official name or whether differences are local. |
| My Table / persistent house rules | **Promising but insufficient evidence** | Preservation/documentation pain is real; repeated retention and willingness to pay for persistence are not established. |
| Teaching/onboarding | **Strongly supported** | Hosts create aids and carry cognitive load; pain often falls as the group learns. |
| Table administration | **Supported** | Scores, rounds, winds, settlement and shared state create repeated work; one authoritative table surface is a strong pattern. |
| Saved games/history | **Promising but insufficient evidence** | Explicitly useful in some products, but not a leading pain across the sample. |
| Voice entry | **Primarily a solution rather than a job** | Low-friction physical-state entry is supported; comparable first-person voice demand was not found. |
| Camera/photo entry | **Primarily a solution rather than a job** | Real use and payment signals exist, but it is technically difficult and competitively served. |
| PWA/home-screen installation | **Primarily a solution rather than a job** | Convenient/offline access can help; users do not express installability itself as the value. |

## Overall

The hypotheses that survived best are those tied to reducing table interruption. Attractive solution ideas should compete on the same outcome: **hand/session state to accepted result with minimum cognitive and social disruption**.
