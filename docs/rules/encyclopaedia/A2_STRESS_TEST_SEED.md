# #251 A2 relationship stress-test seed

Status: **pre-runtime candidate set only — not a completed crosswalk**  
Date: 19 September 2026  
Parent: #251

## Purpose

Give 251A2 a small, high-information starting set once executable Buzzard/MCR/Riichi identities exist.

These candidates are deliberately chosen to test different relationship failure modes. **No relationship below is asserted as fact before A2 compares source + runtime semantics.**

## Candidate 1 — Thirteen Orphans / Thirteen Unique Wonders / Kokushi Musou

Why this is useful:

- strong visible structural similarity across several families;
- different local names;
- different scoring grammars/values;
- likely profile-specific wait, combination and event rules;
- excellent candidate for the first genuine multi-profile page if A2 proves one canonical concept is justified.

A2 must compare:

- exact tile predicate;
- pair/duplicate requirements;
- open/concealed rules;
- legal winning method;
- wait-specific treatment;
- combination/suppression behaviour;
- profile-local value/tier;
- event exceptions such as robbing a Kong where applicable.

Do not assume that a shared 13-terminal/honour shape makes every treatment semantically identical.

## Candidate 2 — Wriggling Snake name collision

Why this is useful:

- Search Console already shows `wriggling snake mahjong` visibility;
- published Mahjong sources use `Wriggling Snake` for materially different tile structures;
- this is the clearest test that A2 must **not merge by name**.

A2 should explicitly prove whether each source-local item is:

- the same implemented concept;
- a sourced alias for another concept;
- a materially different concept sharing a name;
- or a related but distinct snake-family hand.

Public consequence: a search visitor may need a disambiguation treatment such as `Wriggling Snake can mean different hands under different rules`, with exact rule-profile/source context rather than one universal definition.

## Candidate 3 — Knitting / Triple Knitting vs knitted MCR concepts

Why this is useful:

- Search Console already shows `triple knitting mahjong` and `seven honors and knitted` visibility;
- `knitting`, `triple knitting`, `knitted straight`, and honour/knitted special shapes are easy to conflate linguistically;
- likely good test of partial analogue / related-but-different relationships.

A2 must compare actual tile predicates rather than words containing `knit/knitted/knitting`.

## Candidate 4 — Big Three Dragons / Three Great Scholars

Why this is useful:

- likely shared structural core across several profiles;
- excellent test of one canonical detector with profile-local name/value/treatment;
- can expose differences in what completes the rest of the hand and what combines with the pattern.

Do not equate `same three Dragon sets` with identical whole-hand qualification automatically.

## Candidate 5 — Nine Gates / Gates of Heaven family

Why this is useful:

- similar iconic 1112345678999 structure appears across families;
- concealment, wait form and value/tier may differ;
- tests whether A2 needs narrower/broader relationships rather than exact equivalence.

## Candidate 6 — All Green / Imperial Jade family

Why this is useful:

- visual/tile-set overlap can make two concepts appear identical;
- some rules may define a whole-hand tile restriction while another published special hand may impose a narrower set/shape condition;
- good narrower/broader stress test.

## Candidate 7 — Seven Pairs family

Why this is useful:

- seven-pair structures occur across multiple rules families;
- some profiles treat them as an ordinary alternate winning shape, some as a named scoring pattern, and some attach additional restrictions;
- tests separation of hand legality/shape from scoring treatment.

## Candidate 8 — Heavenly / Earthly event hands

Why this is useful:

- event conditions rather than tile predicates drive the concept;
- names such as Heaven's Blessing / Heavenly Hand / Earth's Blessing / Earthly Hand can look equivalent while exact first-draw/first-discard conditions differ;
- tests whether canonical concepts can represent event-based rules cleanly.

## Proposed first 251B trio — only after A2

If A2 evidence supports it, a particularly strong three-page vertical proof would be:

1. **Thirteen Orphans / Thirteen Unique Wonders** — genuine multi-profile concept candidate;
2. **Wriggling Snake** — explicit name-collision/disambiguation case;
3. **Triple Knitting / knitted-family candidate** — partial-analogue case.

This trio is attractive because it simultaneously exercises the relationship model **and** corresponds to named-hand queries already appearing in this site's Search Console data.

A2 may replace any of these if executable/source comparison proves a cleaner test case.

## Research rule

For each candidate, A2 should produce a matrix with at least:

```text
source-local item ID
rules profile / source
runtime detector/binding identity
local name / aliases
exact tile/event predicate
ordinary vs irregular decomposition
open/concealed requirements
winning-method/context requirements
value/tier
combination/suppression rules
proposed relationship
relationship evidence
unresolved differences
```

The crosswalk decision is valid only when the semantic comparison supports it. Search similarity, translated names, historical convention and visual resemblance are discovery aids, not proof.
