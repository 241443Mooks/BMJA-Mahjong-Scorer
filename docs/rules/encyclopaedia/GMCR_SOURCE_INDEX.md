## Source pin

Current accessible rules/scoring source:

- GMCR overview: http://mahjong.wikidot.com/rules:gmcr-overview
- GMCR scoring: http://mahjong.wikidot.com/rules:gmcr-scoring

The accessible source presents **Guangdong Mahjong Competition Rules (GMCR)** as a named synthetic competitive ruleset built from recurring Guangdong-style scoring conditions. It is not treated here as a universal description of generic Guangdong Mahjong.

The scoring page links an “Official Rulebook” PDF, but this research pass did not independently recover and verify that PDF outside the current publishing site. Therefore the evidence grade for 251A1 is **named published profile / secondary-curated source**, not governing-body primary authority.

## Catalogue facts

The current published GMCR scoring page states:

- **56 total winning conditions**;
- additive scoring;
- minimum winning value: **4 points**;
- normal counted cap: **24 points**;
- some extraordinary patterns score **36 points**;
- higher patterns can suppress inferred lower patterns;
- a tile cannot be reused in multiple decompositions for scoring;
- the same pattern cannot be repeatedly counted using the same tiles;
- multiple winners may win from one discard under the published settlement model.

The published catalogue is grouped around source-local families including Classic Hong Kong, New 6, New 18 and a later “15 Acquaintances” set.

## 251A1 treatment

For Encyclopaedia preparation, admit **56 GMCR-local scoring-condition records**.

The GMCR scoring page remains the item-level authority for those 56 entries in this A1 pass. This file intentionally does not copy the entire scoring table and therefore does not become a second rulebook.

Do **not** infer that similarly named entries are automatically equivalent to MCR, Zung Jung, Riichi, BMJA, Hong Kong Old Style, Taiwanese or other Guangdong-family concepts. That comparison belongs to 251A2 after executable identities exist.

## Important scope distinction

The separate Mahjong Wiki “Guangdong Style” scoring page compares multiple historical/modern Guangdong rulesets and explicitly contains variation. It is useful comparative evidence but is **not** admitted as one canonical generic Guangdong profile.

GMCR is admitted precisely because it is a bounded named ruleset with a finite published catalogue.
