## Source hierarchy for next pass

Prefer evidence in this order:

1. current edition of Thompson & Maloney primary rulebook;
2. current Max Robertson edition;
3. publisher descriptions / previews;
4. current Australian U3A/council/group rules where they explicitly name their source;
5. specialist secondary references such as Sloper for terminology/history;
6. apps/forums only as evidence of current language and user demand, not scoring authority.

## Product consequence

The eventual public page can safely explain **relationship and identification** now.

A future selectable Australian rules profile should wait until we have a primary-source rules matrix precise enough to test. Search terminology must never become an implicit scoring ruleset.
