# Issue #72 search opportunity notes

First-pass searches for terms such as:

- western mahjong scoring calculator
- western mahjong calculator
- western mahjong rules
- australian mahjong scoring
- australian mahjong calculator

returned a fragmented mix of:

- specialist Q&A/reference pages;
- books and publisher pages;
- Australian U3A/community pages;
- a small number of apps;
- generic Mahjong-variant pages.

No single browser-based Western/Australian scoring calculator clearly dominated this first research pass.

Treat this only as **directional market evidence**, not a ranking claim. Search results vary by engine, location, personalisation and time.

The page opportunity is therefore strongest when framed as:

1. answer the ambiguity around “Western Mahjong” better than existing pages;
2. explain British vs Australian compatibility honestly;
3. capture calculator intent without falsely claiming the current scorer supports every Western ruleset;
4. create a future landing point for a named Australian rules profile if product evidence later justifies building one.
