# Help screenshots

Generated by `pnpm --filter @workspace/mahjong-scorer screenshots:help`.

These are deterministic real-product captures used as the shared Mahjong Reference product screenshot library. The current core catalogue contains ten journey states with Mobile, Tablet and Desktop captures (30 PNG files in total); Help uses a subset and other product surfaces may reuse the same states.

Do not edit or crop the PNGs manually. Regenerate them from the capture script when the documented UI changes. The capture command initialises the pinned Mahjong tile-artwork submodule and fails if required product images are broken or unresolved.
